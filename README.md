# 25-BLOG-POST-API-MIDDLEWARE


A complete REST API built using Node.js and Express.js for managing blog posts with CRUD operations, custom middleware, request validation, and centralized error handling.



** Features**

 Create, Read,Update, Delete blog posts
 Custom Logger Middleware
 Request Validation Middleware
 Global Error Handling
 RESTful API Structure
 JSON Request & Response
 In-memory Data Storage
 Beginner-Friendly Folder Structure




 **Technologies Used**
 Node.js
 Express.js
 Nodemon
 REST API
 Postman
